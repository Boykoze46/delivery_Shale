# Shale — меню ресторана

В репозитории должны лежать все файлы из этой папки рядом друг с другом:

- `index.html` — разметка сайта
- `style.css` — стили сайта
- `script.js` — меню, переключение RU/KK и навигация
- `.nojekyll` — служебный файл для GitHub Pages

## Публикация через GitHub Pages

1. Распакуйте ZIP на компьютере.
2. Откройте корень своего GitHub-репозитория.
3. Нажмите **Add file → Upload files** и загрузите именно файлы из распакованной папки, а не ZIP-архив и не вложенную папку.
4. Убедитесь, что `index.html`, `style.css` и `script.js` находятся в корне репозитория на одном уровне.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем **Save**.
7. Подождите завершения публикации и откройте ссылку, указанную в Settings → Pages.

## Важно

Сайт не требует сервера или базы данных. Для оформления используются Tailwind CDN, Google Fonts и Font Awesome, поэтому при открытии сайта нужен интернет. Если сайт не открывается, проверьте вкладку **Actions** в репозитории и убедитесь, что GitHub Pages включён и главная страница лежит именно в корне.
